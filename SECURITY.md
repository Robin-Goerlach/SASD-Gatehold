# Security policy

## Supported versions

SASD Gatehold is currently pre-alpha and has no production-supported release.
All builds must be treated as development software for isolated labs.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability or include
exploit details, credentials, private keys, sensitive logs, or packet captures
in public discussions.

Use GitHub's private vulnerability-reporting facility for this repository when
available. If it is not available, contact the repository owner privately
through the contact method listed on the owner's GitHub profile and provide
only enough initial detail to establish a secure communication channel.

A useful report includes the affected commit or version, environment, impact,
reproduction outline, and any suggested mitigation. Sanitize all diagnostic
material before sharing it.

## Disclosure approach

The project will acknowledge valid reports, investigate them, prepare a fix and
tests, and coordinate disclosure appropriate to the risk. Formal response-time
and supported-version commitments will be published before the first stable
release.

# Technical reference

This section will become the authoritative reference for:

- `gateholdctl` commands and exit codes;
- REST API and controller protocol versions;
- configuration and migration schemas;
- event fields, stable event IDs, and correlation rules;
- native files managed by Gatehold;
- support-bundle manifest and redaction behavior;
- package contents and filesystem layout.

Interfaces are not stable during pre-alpha development unless explicitly marked
otherwise.
